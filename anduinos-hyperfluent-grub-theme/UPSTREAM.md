# Upstream source

The theme artwork and icons come from the AnduinOS variant of
[HyperFluent-GRUB-Theme](https://github.com/Anduin2017/HyperFluent-GRUB-Theme/tree/feat/anduinos-theme/anduinos),
at commit `6db5bb74760c37af6a0b92e326dc30522e6b8c75`.

The theme configuration is adapted to fit AnduinOS Live and installed menus
and to use the trusted Unicode font supplied by signed Ubuntu GRUB. Upstream
DIN and Terminus PFF2 fonts are deliberately not distributed because signed
GRUB denies loading external fonts under Secure Boot.
