# Coding agent logos

Names and marks belong to their respective owners; inclusion does not imply endorsement.
SVGs retain the upstream artwork and proportions. Root viewport dimensions are set to 96 pixels wide for GTK rasterization (CSS `1em` intrinsic sizes otherwise render as a single pixel). No runtime image downloads are required.
