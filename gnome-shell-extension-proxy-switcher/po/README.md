# Translation sources

These compact catalogs were reconstructed from the translation binaries in
the upstream GNOME Extensions releases recorded in `../UPSTREAM.md`. Upstream
generated them from GNOME Control Center translations and distributed them as
part of Proxy Switcher.

The package build validates every catalog and compiles it into the extension's
`locale` directory. Edit the `.po` files here; generated `.mo` files are not
tracked.
